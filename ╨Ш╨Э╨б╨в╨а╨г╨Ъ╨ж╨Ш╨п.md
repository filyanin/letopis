# Летопись героя на GitHub Pages

В папке лежат файлы приложения:

| Файл | Что это |
|---|---|
| `index.html` | само приложение |
| `sw.js` | работа без интернета |
| `manifest.webmanifest` | название и иконка для экрана «Домой» |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | иконки |
| `.nojekyll` | служебный пустой файл для GitHub, его тоже нужно загрузить |

Эту инструкцию загружать не обязательно.

## 1. Выложить приложение (один раз, с компьютера)

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Справа вверху нажмите «+» → **New repository**.
   - **Repository name**: например `letopis`.
   - Выберите **Public**: на бесплатном тарифе GitHub Pages работает только для открытых хранилищ. Герои игроков туда не попадают, они хранятся на телефонах.
   - Нажмите **Create repository**.
3. На странице нового хранилища нажмите ссылку **uploading an existing file**.
4. Перетащите в окно все файлы из папки `letopis`, включая `.nojekyll`.
   - На Mac файлы с точкой в начале имени скрыты. Чтобы их увидеть, нажмите в Finder **Cmd + Shift + .**
   - Если `.nojekyll` не загрузится, ничего страшного: приложение будет работать и без него.
5. Внизу нажмите **Commit changes**.
6. Откройте **Settings** → в меню слева **Pages**.
   - **Source**: Deploy from a branch.
   - **Branch**: `main`, папка `/ (root)` → **Save**.
7. Подождите 1–2 минуты и обновите страницу. Вверху появится адрес вида
   `https://ВАШ-ЛОГИН.github.io/letopis/`.
   Этот адрес и рассылайте игрокам.

## 2. Поставить на айфон (каждый игрок)

1. Откройте адрес **в Safari**, обязательно с интернетом.
2. Подождите несколько секунд, пока приложение загрузится и сохранится.
3. Нажмите «Поделиться» (квадрат со стрелкой) → **На экран „Домой“** → **Добавить**.
4. Дальше открывайте приложение **с иконки «Летопись»**, а не из Safari.

Важно: на айфоне приложение с иконки и вкладка Safari хранят героев **раздельно**. Создавайте и ведите героев в приложении с иконки. Если героя уже завели в Safari, перенесите его: скачайте `.save` в Safari и откройте этот файл в приложении.

На андроиде: откройте адрес в Chrome → меню «⋮» → **Добавить на главный экран** (или **Установить приложение**).

## 3. Работа без интернета

После первого открытия с интернетом приложение запускается и без сети. Шрифт со старорусскими буквами тоже сохраняется при первом открытии с интернетом. Если в тот раз он не успел загрузиться, без сети будет обычный шрифт, а при следующем открытии с интернетом всё подтянется.

## 4. Сохранение героев

- Всё, что вы меняете, сохраняется на телефоне само.
- **Кнопка со стрелкой вниз** в шапке героя: на айфоне откроется окно «Поделиться». Выберите **Сохранить в «Файлы»**, отправьте файл себе в мессенджер или по AirDrop.
- **«Открыть .save»** на главной: выберите сохранённый файл.
- Время от времени сохраняйте `.save`. Если удалить иконку приложения или очистить данные Safari, герои на телефоне пропадут.

## 5. Обновить приложение

1. В хранилище на GitHub нажмите **Add file** → **Upload files** и загрузите новый `index.html` (и другие изменённые файлы) поверх старых → **Commit changes**.
2. Откройте `sw.js` прямо на GitHub (значок карандаша) и увеличьте число в строке
   `const VERSION = 'letopis-v9';` (например, на `letopis-v10`) → **Commit changes**.
3. У игроков новая версия появится, когда они откроют приложение с интернетом. Если сразу не появилась, закройте приложение и откройте ещё раз.

Герои игроков при обновлении сохраняются.

## 6. Мастер и игроки: дары, карты, тайные заявки

Всё передаётся без интернета-сервера: QR-кодом, ссылкой, кодом или файлом.

- **Дар героям.** Стол мастера → «Дары»: соберите вещи, монеты, чары, знания, супостатов, знакомцев → «Показать QR-код». Игрок открывает своего героя и жмёт **значок подарка** в шапке.
- **Карта места.** Стол мастера → «Места» → откройте место → «Показать игрокам». Туман и скрытое игроки не увидят. Карта ложится герою во вкладку «Мир».
- **Тайная заявка.** Игрок жмёт **значок конверта** в шапке героя, пишет заявку и показывает мастеру QR-код со словом «Заявка». Мастер: «Заявки» → «Сканировать» или «Вставить код».

С сайта на GitHub Pages QR-код содержит ссылку: его можно навести **обычной камерой телефона**.

Важно для айфона: камера откроет ссылку в Safari, а герои живут в приложении с иконки. В этом случае на экране дара будет кнопка **«Скопировать дар»** — нажмите её, откройте приложение с иконки и вставьте код: значок подарка → поле «Код или ссылка».

На андроиде в Chrome QR-код можно сканировать прямо в приложении: кнопка «Сканировать QR».

## 7. Стол мастера: история, бой, места

- **История.** Делится на сюжеты, у каждого свой граф сцен. «Вести игру» — быстрый режим: на карточке сцены отмечайте, **кто из героев её прошёл**. На графе цветные дорожки показывают выборы каждого героя, строка «Путь героя» подсвечивает путь одного.
- **Бой.** У участников есть **скорость** и **токены состояний** (кровотечение, оглушён, в захвате и др., можно своё). Счётчик ходов у токена убывает сам в начале хода участника.
- **Места.** Вкладки кистей: Местность, Малая и Большая карта, Приказы и управа, Лес, Пещеры и подземелья, Погост и пожарище. При создании места можно начать с заготовки (засада у бревна, святой источник, грот, старые ходы, погост, пожарище). Туман снимается кистью 1, 3×3, 5×5 или «Комната».
- **Примеры.** Три героя и пять сюжетов стартовой истории в Новом царстве с местами, супостатами, дарами, боями, грамотами и часами угроз. Убрать их — кнопка «Убрать примеры» на главном экране.

## 8. Экран игроков (версия 8)

- Нужен компьютер, к которому телевизор подключён **вторым монитором в режиме «Расширить»** (HDMI, AirPlay «как отдельный дисплей», Miracast Win+K → «Расширить»).
- Стол мастера → место, бой или QR-код дара → **«Экран игроков»**. Разрешите всплывающие окна, перетащите окно на телевизор, «Во весь экран».
- Всё, что мастер меняет, появляется на экране сразу. Подробности — в справке мастера (значок книги на столе мастера) и в `README.md`.

## 9. Грамоты и время (версия 9)

- **Грамоты.** «История» → «Грамоты»: официальная грамота, полусожжённая записка, береста. «На экран» — крупно на экране игроков. «Игроку тайно» — QR-код только с этой грамотой: игрок сканирует его значком подарка, грамота ложится в «Записи» → «Грамоты». Счётчик рядом показывает, влезает ли грамота в QR-код.
- **Время.** «История» → «Время»: часы, день недели, дата, праздники, луна, погода, лист месяца. Кнопка «Календарь» — свои месяцы, неделя, луна, праздники и посты.
- **Время сцен.** В узле истории задайте, сколько длится сцена; в игре поправьте («Нет», «Лихо», «Провозились»…) — время сдвинется само, когда герои пойдут дальше.
- **Часы угроз** со сроком иссякают сами в назначенный день.
